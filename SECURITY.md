# Security Policy

## Supported versions

Only the latest `main` branch receives security fixes.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Xyzjesus/omp-compress-studio/security/advisories/new).

Do not open a public issue for security reports.

This repository runs automated security scans (OpenSSF Scorecard, zizmor, gitleaks, Trivy) on every push; results appear in the Security tab.
